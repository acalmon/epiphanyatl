# The Epiphany Guide to Social Enterprise

A field guide for volunteers of the Epiphany program at First Presbyterian Church of Atlanta — navigators, screeners, judges, and donors.

Published at https://guide.epiphanyatl.org via GitHub Pages. The site is a single self-contained `index.html`; edit it and push to update the live page. Additional pages added to this repository will appear under the same domain (e.g. `guide.epiphanyatl.org/page.html`).
